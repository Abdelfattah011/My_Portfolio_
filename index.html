University Network Architecture

Cisco Packet Tracer | VLANs, ACLs, DHCP & DNS
Situation
Multi-building university campuses face severe broadcast overhead, IP conflicts, and security risks when operating on flat, unsegmented network topologies.
Task
Design and simulate a scalable, secure enterprise network architecture linking administrative, academic, and student buildings with strict access controls.
Action
Segmented departmental traffic using custom VLANs and subnetting; configured Inter-VLAN routing, centralized DHCP/DNS servers, and enforced Extended ACLs to block unauthorized cross-department traffic.
Result
Achieved 100% logical isolation for sensitive administrative servers, eliminated broadcast storms, and established a scalable blueprint for campus-wide connectivity.
